# betbuilder-dashboards — Claude Instructions

## Free Bet Offer copy: mandatory process

**Before writing any offer copy for a bookmaker, you MUST fetch the freebets.com review page for that bookmaker and read the current offer from it.**

The review URL pattern is:
```
https://www.freebets.com/betting-sites/reviews/<bookmaker-slug>/
```

Examples:
- Playzee → https://www.freebets.com/betting-sites/reviews/playzee/
- BetMGM → https://www.freebets.com/betting-sites/reviews/betmgm/
- Paddy Power → https://www.freebets.com/betting-sites/reviews/paddy-power-sports/
- betway → https://www.freebets.com/betting-sites/reviews/betway/
- bet365 → https://www.freebets.com/betting-sites/reviews/bet365/
- Ladbrokes → https://www.freebets.com/betting-sites/reviews/ladbrokes/
- tote → https://www.freebets.com/betting-sites/reviews/tote/

Do NOT rely on web search results or training knowledge for offer details — these are frequently wrong or outdated. The review page is the only authoritative source.

Fetch all three bookmaker review pages before writing any copy, then use the exact headline deal, qualifying conditions, minimum deposit, minimum odds, free bet value, and any promo code shown on those pages.
